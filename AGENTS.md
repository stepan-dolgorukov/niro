# AGENTS.md — Инструкции для AI-агентов: отчёт о преддипломной практике (УрФУ)

## Назначение

- В репозитории находятся три документа в LaTeX для оформления отчёта о преддипломной практике УрФУ
  (направление `10.05.01` «Компьютерная безопасность»):
  - `report/report.tex` — **отчёт о практике** (основной рабочий документ);
  - `assignment/assignment.tex` — задание на практику (форма);
  - `review/review.tex` — отзыв/характеристика руководителя (форма).
- **Главный артефакт** — PDF отчёта, полностью соответствующий требованиям ГОСТ 7.32–2017.

## Часть I — Инструкции для агента

### 1. Проект

- Сборка: **XeLaTeX** (UTF-8, `fontspec`, шрифт Times New Roman из `corefonts`).
- Сборка воспроизводится через Nix Flakes (`flake.nix`): `texliveSmall`, `texstudio`, обёртка
  `compile.sh`, `FONTCONFIG_FILE` с корпоративными шрифтами.

### 2. Приоритет источников требований

1. **Часть II этого файла** — полный свод требований (GOST 7.32–2017 + ЭОР УрФУ, 2022).
   **Перед любой правкой оформления — сверяться с ней.**
2. `Оформление_ВКР_требования_стандарта_УрФУ_2022.pdf` (в корне) — первоисточник (ЭОР).
   Формулировки со ссылками вида «с. 40» — по печатной нумерации PDF.
   PDF модель не читает напрямую; текст извлекают через `pypdf` или `pdftotext` в `nix develop`.
3. Шаблон `report/report.tex` — реализация требований; преамбула задаёт поля, кегли, интервалы, нумерацию, подписи.

**Правило разрешения конфликтов:** требования → всегда в приоритете; при конфликте форма кафедры
(макет титульного листа, задания, отзыва) → форма кафедры, но **обязательно сообщить пользователю
о расхождении**.

### 3. Сборка и проверка

```bash
nix develop                                          # окружение (LaTeX, шрифты, compile.sh)

compile.sh                                          # все три документа (2 прогона)
compile.sh report/report                            # только отчёт

# ручной запуск (из каталога документа; compile.sh сам делает cd)
cd report && xelatex -interaction=nonstopmode -halt-on-error report.tex && xelatex report.tex
```

**Поведение `compile.sh`:** перед запуском `xelatex` он **переходит в каталог исходника** (`cd` + базовое
имя файла). Выходные файлы (`.aux`, `.log`, `.toc`, `.pdf`) создаются **рядом с `.tex`**; в корне
репозитория после сборки артефактов быть **не должно**.

**Обязательные проверки после сборки:**

```bash
grep -E '^! |LaTeX Error|Undefined control' report/report.log   # ошибок быть не должно
grep -n 'There were undefined references' report/report.log    # пусто = ссылки сошлись
grep -a "Output written" report/report.log                     # число страниц
ls *.aux *.log *.toc report.pdf 2>/dev/null                    # в корне быть не должно
```

- `compile.sh` завершается **ненулевым exit-кодом** при ошибке (`set -e` + `-halt-on-error`) —
  поэтому `compile.sh … && <проверки>` — надёжный страж.
- Первый прогон `nix develop` может печатать `warning: Git tree ... is dirty` — это не ошибка.
- Системные `pdfinfo`/`pdftotext` вне `nix develop` не работают (несовместимость glibc).

### 4. Жёсткие правила оформления (MUST — нарушение = правка отклоняется)

#### 4.1. Параметры страницы и текста

| Параметр | Значение |
|---|---|
| Формат / сторона | A4, односторонняя печать |
| Поля | левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм |
| Абзацный отступ | 1,25 см (`\Абзац=35.4pt`) |
| Шрифт | Times New Roman, чёрный |
| Кегль | 14 pt основной текст; 12 pt таблицы, надписи, подрисуночные подписи |
| Интервал | 1,5 (база 24,15 pt при 14 pt) |
| Переносы слов | запрещены (`\hyphenpenalty=10000` — не снимать) |

#### 4.2. Заголовки и нумерация

- Заголовки структурных элементов: **полужирные, ПРОПИСНЫЕ, по центру, без точки, без подчёркивания**,
  каждый элемент — **с новой страницы**.
- Разделы: `1 Наименование` (полужирный, с абзацного отступа, без точки в конце номера).
  Подразделы: `1.1 Наименование`. Пункты/подпункты (`1.1.1`) — только номер, без заголовка.
- Слово **«глава» не используется** (ГОСТ 7.32 не допускает).
- Точка после заголовка не ставится; несколько предложений в заголовке разделяются точкой;
  перенос слов в заголовках и подписях рисунков/таблиц запрещён, в т. ч. на союзе/предлоге.
- Страницы: арабские, внизу по центру, без точки, сквозные, включая приложения.
  Титульный лист включается в нумерацию, но номер на нём не печатается (`\pagestyle{empty}`).
  Лист А3 считается за одну страницу.

#### 4.3. Рисунок / таблица / формула / приложение

- Каждый рисунок и таблица **должны иметь ссылку в тексте**; слово пишется полностью, без сокращения:
  `рисунок 2`, `Таблица 3` (не «рис.», не «табл.», не «см. рисунок выше»).
  В середине предложения — строчными и согласованно по падежам; в нумерационном заголовке — с прописной.
- Подпись рисунка: **под** рисунком, по центру, без точки: `Рисунок N – Наименование`;
  экспликация — перед подписью.
- Подпись таблицы: **над** таблицей, слева, без абзацного отступа: `Таблица N – Наименование`.
  Диагональные разделители в шапке запрещены; заголовки граф — по центру, боковика — по левому краю.
- **Раздел не может заканчиваться рисунком или таблицей** — после них обязателен вывод/анализ
  не менее одного абзаца.
- Формулы: отдельной строкой, посередине, ≥1 свободной строки выше/ниже, номер в круглых скобках
  справа `(1)`; экспликация со слова `где` **без двоеточия**, каждое значение — новой строке,
  конец — точка с запятой; знаки подобия и функции (`max`, `lg`, `Re`) — прямым, латинские обозначения
  величин — курсивом.
- Приложения: с новой страницы, `ПРИЛОЖЕНИЕ А` / `(обязательное)` / заголовок ПРОПИСНЫМИ по центру
  без точки; буквы кириллицы **кроме Ё, З, Й, О, Ч, Ъ, Ы, Ь**; нумерация внутри приложения с буквой:
  `Рисунок А.1`, `Таблица А.1`, `(А.1)`; все приложения — ссылки в тексте и в содержании.

#### 4.4. Ссылки на источники

- Отсылки — арабские цифры в квадратных скобках: `[5]`, `[5, с. 20]`, диапазон `[2, с. 15–20]`,
  несколько `[1; 4, с. 30]`.
- Список источников — **в порядке появления ссылок в тексте** (не по алфавиту), нумерация `1.`
  с точкой, с абзацного отступа.
- Описание по ГОСТ Р 7.0.5: `Фамилия И. О. Заголовок : вид / авторы. — Город : Издательство, год. — N с.`
  (в ЭОР тире-разделители часто опущены — держать стиль, заданный в шаблоне: `Город: Изд-во, год. N с.`).

### 5. Макросы шаблона `report/report.tex`

Преамбула — «движок» оформления. **Не править без крайней необходимости** — все параметры §4
уже зашиты. Текст писать только макросами.

| Макрос | Назначение |
|---|---|
| `\ОсновнаяЧасть` | Включает нумерацию страниц, кегль 14/1,5, отступ, параметры формул — один раз после титульного листа |
| `\Элемент{…}` | Структурный элемент: новая страница + ПРОПИСНЫЙ полужирный заголовок по центру + запись в содержание |
| `\Элемент*{…}` | То же, но без записи в содержание (звёздочка; внутри `\Содержание`) |
| `\Содержание` | Готовый блок «СОДЕРЖАНИЕ» + автособираемое TOC |
| `\Раздел{…}` | `1 Название` (жирн., абз. отступ), в TOC; счётчик сквозной |
| `\Подраздел{…}` | `1.1 Название`, в TOC |
| `\Пункт` | Печатает `1.1.1 ` и ждёт текст; заголовка не имеет |
| `\Приложение{обязательное}{Название}` | `ПРИЛОЖЕНИЕ А` + `(обязательное)` + заголовок; сбрасывает счётчики рисунков/таблиц/формул, префиксирует буквой |
| `\Рисунок[экспликация]{…}{…}` | Рисунок: экспликация, содержимое, подпись с `\label` |
| `\begin{таблица}{…}` / `\Таблица` / `\ПродолжениеТаблицы` / `\Примечание` | Таблица с автоматической подписью; продолжение; примечание |
| `\begin{equation} … \end{equation}` + экспликация «где» | Формула + пояснение значений |
| `\begin{источники} … \end{источники}` / `\bibitem` / `\cite` | Библиография вручную, порядок = порядок `\cite` |

- Элементы **РЕФЕРАТ**, **ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ**, **ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ** в текущем
  `report.tex` отсутствуют; добавлять через `\Элемент{…}` и текст (см. §5.6).
- Библиография: `\bibliographystyle`/BibTeX **нельзя** — окружение `источники` заточено под ручную нумерацию.
- Изображения: пути в исходнике **относительны каталога документа** (`\includegraphics{fig/arch.pdf}`,
  не `{report/fig/arch.pdf}`); `compile.sh` собирает изнутри `report/` (§3).

### 6. Workflow

1. **Прочитать** Часть II (§23 — чек-лист типовых нарушений) и текущий `report/report.tex`.
2. **Собрать факты** у пользователя / из `assignment/` и `review/`: тема, организация, сроки, задачи,
   фактически делалось, результаты, приложения. **Не додумывать** ФИО, даты, группы, организации, результаты.
3. **Заполнить преамбулу** (`\Исполнитель`, `\Руководитель`, `\Группа`, `\Кафедра`, `\Институт`, `\Тема`,
   `\Код`, `\Специальность`, `\Программа`, `\Начало`, `\Конец`, `\Год`) и структуру.
4. **Писать по элементу за раз**; после каждого рисунка/таблицы — абзац анализа.
5. **Собрать** (`compile.sh report/report`), проверить лог (§3).
6. **Прогнать чек-лист** (§7 DoD), показать пользователю diff и расхождения с формой кафедры.
7. **Коммит**: короткое повелительное наклонение, по-английски, как в истории git
   (`Fill in report introduction`, `Add risk analysis section`); **не смешивать несколько документов
   в одном коммите**. Артефакты сборки не коммитить.

### 7. Definition of Done (чек-лист)

- [ ] `compile.sh report/report` проходит дважды; в `report/report.log` нет ошибок, `undefined references`,
      `Label multiply defined`; в корне артефактов не должно быть (`ls *.aux *.log *.toc report.pdf` пусто).
- [ ] Поля/шрифт/кегли/интервал соответствуют §4.1 (преамбула не менялась без крайней необходимости).
- [ ] Заголовки: ПРОПИСНЫЕ, полужирные, без точки, каждый элемент с новой страницы.
- [ ] Нет слова «глава», нет «гл.», нет `рис.`/`табл.` — только полное `рисунок N` / `таблица N`.
- [ ] На каждый рисунок, таблицу, формулу и приложение есть ссылка в тексте; `\bibitem` сверить с `\cite`.
- [ ] После каждого рисунка/таблицы — абзац анализа; раздел не кончается иллюстрацией.
- [ ] В перечислениях — `\Тире{}`-тире/корректные метки, а не `-`.
- [ ] Формулы: номер справа в `( )`, экспликация `где` без двоеточия, каждая величина с новой строки, `;` в конце.
- [ ] Приложения: буквы без Ё, З, Й, О, Ч, Ъ, Ы, Ь; статус `(обязательное)`/`(справочное)`; нумерация внутри с буквой.
- [ ] Отсылки `[N]` / `[N, с. M]`, список — по порядку появления.
- [ ] Реферат ≤ 1 стр., 5–15 ключевых слов (если используется).
- [ ] Объём в диапазоне (30–60 стр. для бакалавра); не «надувать» пустыми строками (`\пусто`).
- [ ] Фактические данные (ФИО, сроки, организация) — подтверждены пользователем.
- [ ] Изменения закоммичены; артефакты сборки не попали в git.

### 8. Стиль текста

- Русский язык, научно-технический стиль, безличность или «мы/автор» последовательно.
- Термины — единообразно; при первом использовании латинский термин — курсивом (in vivo и т. п.).
- Числа и единицы — по SI; обозначения величин — курсивом, единицы — прямым.
- Не использовать «watermark»-фразу, метафоры, разговорные обороты.
- Аббревиатуры: при первом упоминании — расшифровка; более трёх обозначений — перечень сокращений.

### 9. Ограничения агента

1. Не менять `flake.nix`, преамбулу «движка» (`wpar`, `wsz`, `geometry`...) и настройки шрифтов/полей —
   только если пользователь явно попросил. Исключение (сделано по просьбе): `compile.sh` в `flake.nix`
   **намеренно** делает `cd` в каталог исходника, чтобы артефакты лежали рядом с `.tex` (§3). Не
   «упрощать» обратно — иначе артефакты снова уйдут в корень.
2. Не переписывать структуру `report/report.tex` на другой шаблон/класс (например, `reportsum`, `biblatex`,
   `\chapter` из other classes) — документ на `article` + свои макросы.
3. Не выдумывать содержание практики: нет данных — спрашивать.
4. Не «чинить» замечания нормоконтролёра молча: показывать diff, описывать, какое требование
   из какого раздела Части II закрыто.
5. При расхождении ЭОР и формы кафедры — решать в пользу формы кафедры и писать об этом.
6. Не трогать `*.docx` и исходные PDF в корне (это артефакты кафедры; в git игнорируются).

## Часть II — Справочник требований к оформлению

> **Нормативная база:** ГОСТ 7.32–2017 (СИБИД); приказ УрФУ № 944/03; ГОСТ Р 7.0.5–2008; ГОСТ 7.80/7.82,

### 1. Общие требования к оформлению

#### 1.1. Сводка технических параметров

| Параметр | Требование |
|---|---|
| Носитель текста | одна сторона листа белой бумаги А4 |
| Поля | левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм |
| Абзацный отступ | 1,25 см (единый) |
| Гарнитура | Times New Roman |
| Цвет шрифта | чёрный |
| Кегль основного текста | 14 pt |
| Кегль таблиц, надписей, подрисуночных подписей | 12 pt |
| Междустрочный интервал | 1,5 |
| Заголовки 1 и 2 уровней | полужирное начертание |
| Заголовки 1 уровня | ПРОПИСНЫЕ |
| Заголовки 2 и ниже | строчные |
| Выравнивание текста | по ширине, с абзацного отступа |

#### 1.2. Детализация

- Поля несимметричны из-за переплёта; настраивать **до начала** оформления.
- Настройка в MS Word: Макет → Поля; абзацный отступ 1,25 см; стили заголовков; нумерация страниц
  внизу по центру + «Особый колонтитул для первой страницы».
- Курсив — для объектов (in vivo, in vitro) и латинских терминов; допустимы иные шрифты для акцентов
  (того же кегля и гарнитуры).

### 2. Структура отчёта и рекомендуемый объём

- Элементы первого уровня: титульный лист; реферат; содержание; термины и определения
  (при наличии); перечень сокращений и обозначений (при наличии); введение; основная часть;
  заключение; список использованных источников; приложения (при наличии).
- Дополнительно (по сноске 4): задание на выполнение практики; перечень листов графических материалов.
- Объём: бакалавр 30–60 стр.; специалист 50–90; магистр 50–120. Для практики конкретный объём
  задаёт программа практики и методические указания кафедры.

### 3. Титульный лист

- Поля и макет: поля титульного листа соответствуют общим (30/20/20/15 мм).
- Обязательные сведения и правила размещения: министерство, организация, грифы СОГЛАСОВАНО/УТВЕРЖДАЮ,
  дата (`20.06.2022`), вид документа, наименование, руководитель, нормоконтрольер, студент, место и год.
- В отчёте о практике вместо «ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА» — вид/наименование документа по
  форме кафедры (например, «ОТЧЁТ»).

### 4. Реферат

- ≤ 1 стр.; оптимум 850 печатных знаков с пробелами; не более одной страницы машинописного текста.
- Строка объёма: `Отчёт 65 с., 18 рис., 25 источн., 1 прил.` (числа — вручную после финальной сборки).
- Ключевые слова: 5–15 слов/сочетаний, именительный падеж, прописные, в строку, через запятые,
  без абзацного отступа и точки в конце.
- Текст реферата отражает: объект, цель, методы, результаты и новизну, область применения,
  рекомендации, оценка эффективности, прогноз.

### 5. Содержание

- Включает: введение, все разделы/подразделы/пункты с названиями, заключение, источники, приложения
  с номерами страниц начала элементов.
- После заголовка — отточие + номер страницы; подразделы — отступ 2 знака, пункты — 4 знака;
  страницы содержания — выровнены по правому краю, соединяются отточием.

### 6. Термины и определения

- Начинается со слов: **«В настоящей работе применяют следующие термины с соответствующими
  определениями»**.
- Список — столбец без знаков препинания в конце; слева без абзацного отступа, в алфавитном порядке;
  справа — через тире определения.

### 7. Перечень сокращений и обозначений

- Начинается со слов: **«В настоящем отчёте применяют следующие сокращения и обозначения»**.
- **Более трёх** обозначений с пояснением → составлять перечень; **менее трёх** — не составлять,
  сведения указывать в тексте или примечании.
- Список — столбец без знаков препинания в конце; слева без абзацного отступа, в алфавитном порядке;
  справа — через тире расшифровка.

### 8. Введение

- MUST содержать: оценку современного состояния проблемы; основание и исходные данные; обоснование
  необходимости; отражать **актуальность и новизну**, **связь с другими работами**; указывать
  **объект и предмет**, **цель** (одна) и **задачи** (`1) …`).
- Дополнительно для практики: место, сроки, вид/тип практики, база; цель практики — сбор материалов
  для ВКР; задачи по этапам практики.

### 9. Основная часть

- Содержательные блоки: (1) выбор направления; (2) процесс исследований; (3) обобщение и оценка
  результатов. Для практики: описание организации-базы, постановка задачи, выполненные работы по
  этапам, полученные результаты и их оценка.

### 10. Заключение

- В конце работы **до списка источников**; содержит: краткие выводы по задачам, оценку полноты
  решения, рекомендации, оценку эффективности и научного уровня.

### 11. Список использованных источников

- Включать документы, отсылки на которые оформлены `[N]`; сведения — по ГОСТ Р 7.0.5, ГОСТ 7.80, ГОСТ 7.82.
- Сведения — в порядке появления ссылок в тексте, нумерация `1.` с точкой, с абзацного отступа.
- Список — затекстовый: отсылка на описание даётся в тексте.

### 12. Приложения

- Что включать: дополнительные материалы, промежуточные доказательства/расчёты, таблицы вспомогательных
  данных, протоколы, инструкции/методики/коды, иллюстрации вспомогательного характера, акты, копии документов.
- Правила: с новой страницы; статус (обязательное/справочное); заголовок `ПРИЛОЖЕНИЕ А` + прописные
  без точки; обозначения — прописные кириллицы, кроме Ё, З, Й, О, Ч, Ъ, Ы, Ь; нумерация внутри с буквой.
- В тексте отчёта — на все приложения ссылки; приложения в порядке ссылок.

### 13. Заголовки структурных элементов

- Уровни: 1-й (структурный элемент / раздел) — полужирный, ПРОПИСНЫЕ, по центру; 1-й (раздел
  основной части) — полужирный, ПРОПИСНЫЕ, с абзацного отступа; 2-й (подраздел) — полужирный,
  строчные; 3-й и ниже — пункт/подпункт, только номер.
- MUST: без точки в конце; несколько предложений — через точку; переносов в заголовках нет;
  заголовки чёткие и краткие; **слово «глава» не используется**.

### 14. Нумерация: страницы, разделы, перечисления

- Страницы: арабские, внизу по центру, без точки, сквозные, включая приложения; титульный лист
  в нумерацию, но номер не печатается; А3 = одна страница.
- Разделы: арабские, без точки, с абзацного отступа; подразделы — номер раздела + подраздел,
  через точку, без точки в конце; **«глава» не допускается**.
- Перечисления: с абзацного отступа в столбик; тире `–` (не дефис); простые — через запятую,
  сложные — через точку с запятой; конкретное число — арабские цифры с скобкой (`1) …`).
- Многоуровневые списки — через нумерцию с подпунктами.

### 15. Иллюстрации

- К иллюстрациям относятся: чертежи, графики, схемы, распечатки, диаграммы, фотоснимки.
- Располагаются после текста, где упоминаются впервые, или на следующей странице.
- MUST: на все иллюстрации — ссылки; слово «рисунок» пишется полностью; подпись — в центре
  под рисунком, без точки; экспликация — перед подписью; переносов в наименовании нет.
- Нумерация: сквозная (`Рисунок 1`) или поглавная (`Рисунок 2.1`); в приложениях — `Рисунок А.3`.

### 16. Таблицы

- Таблица — особая форма передачи содержания; не является рисунком; шрифт ≥ 12 pt; ссылка — до
  таблицы; нумерационный заголовок и тематический — над таблицей слева, без абзацного отступа,
  формат `Таблица N – Наименование`; диагональные разделители запрещены; заголовки граф —
  по центру, боковика — по левому краю; перенос — `Продолжение таблицы N` + перенос головки.
- MUST: раздел не заканчивается таблицей/рисунком — нужен вывод/анализ не менее одного абзаца.
- Нумерация: сквозная или поглавная; тип должен совпадать с типом нумерации рисунков.

### 17. Примечания и сноски

- Примечание: слово «Примечание» с прописной, с абзацного отступа, не подчёркивать; одно — с тире,
  текст с прописной, не нумеруется; несколько — нумеруются арабскими без точки.
- Сноска: знак без пробела после слова/числа; надстрочный, арабские или `*`; сноска — с абзацного
  отступа в конце страницы, отделяется тонкой горизонтальной линией с левой стороны.

### 18. Формулы и уравнения

- Формулы — отдельной строкой, посередине, ≥1 свободная строка выше/ниже; перенос — после
  `=`/`+`/`–`/`×`/`:`, знак повторяется; при переносе умножения — только `×`.
- Нумерация: арабские в круглых скобках в крайнем правом положении: `(1)`; в приложениях — `(В.1)`.
- Экспликация: под формулой, в той же последовательности, первая строка — со слова «где» (без
  двоеточия), абзацный отступ; каждое значение — новой строке; конец — точка с запятой.

### 19. Шрифтовое оформление обозначений

- Буквы латинского алфавита, обозначающие физические величины, — курсивом; цифры — прямым.
- Буквы греческого/немецкого готического/русского алфавита — шрифтом прямого начертания.
- Векторные величины — курсивным полужирным (или прямым полужирным/с стрелкой наверху).
- Индексы: латинские буквы курсивом; сложные индексы — по правилам (точки для русских слов, без
  разделения для цифр/лат/греч, запятая для нескольких чисел, точка с запятой для дроби).
- Химические обозначения: символы элементов — прямыми прописными, конфигурации L/D/R/S — прописными
  курсивными, особенности строения — строчными курсивными.

### 20. Библиографические ссылки

- В тексте: арабские цифры в квадратных скобках в конце ссылки: `[5, с. 20]`, `[2, с. 15–20]`.
- Список источников — в порядке появления, нумерация `1.` с точкой, с абзацного отступа.
- Затекстовая ссылка содержит: заголовок, основное заглавие, обозначение материала, сведения об
  ответственности, издании, выходные данные, физическую характеристику и др.

### 21. Оформление ссылок по типам документов

- 21.1. Книга одного/двух/трёх авторов: `Фамилия И. О. : вид / авторы. — Город : Изд-во, год. — N с.`
- 21.2. Книга четырёх и более соавторов: без первого автора в заголовке; `Фамилия И. О. / … : под ред. …`.
- 21.3. Многотомные издания, 21.4. Статьи, 21.5. Стандарты, 21.6. Законы РФ, 21.7. Диссертации,
  21.8. Архивные документы, 21.9. Электронные ресурсы: URL + `(дата обращения: дд.мм.гггг)`.

### 22. Пошаговый алгоритм оформления

1. До набора текста: поля, шрифт, интервал, абзац, стили заголовков, нумерация страниц.
2. Титульный лист.
3. Реферат (≤ 1 стр.).
4. Содержание (автоб).
5. Термины/сокращения при наличии >3 обозначений.
6. Введение.
7. Основная часть.
8. Заключение.
9. Список источников.
10. Приложения.
11. Проверка: чек-лист §23 и вопросы §24.

| Требование ЭОР | Реализация в `report/report.tex` |
