# AGENTS.md — работа AI-агента над отчётом о преддипломной практике

Инструкция для AI-агентов (Claude Code, OpenCode и др.), которые пишут или правят
отчёт о прохождении преддипломной практики в этом репозитории.

**Файл состоит из двух частей:**

- **Часть I** (§1–§12) — рабочие инструкции: проект, сборка, макросы шаблона, workflow,
  ограничения, Definition of Done.
- **Часть II** (§1–§27) — полный справочник требований к оформлению по ГОСТ 7.32–2017
  и ЭОР УрФУ (2022), встроенный вместо ранее существовавшего отдельного файла требований.

---

## 1. Что это за проект

Репозиторий содержит **три документа в LaTeX** для оформления преддипломной практики УрФУ
(направление `10.05.01 Компьютерная безопасность`):

| Каталог | Файл | Назначение |
|---|---|---|
| `report/` | `report/report.tex` | **Отчёт о практике** — основной рабочий документ |
| `assignment/` | `assignment/assignment.tex` | Задание на практику (форма) |
| `review/` | `review/review.tex` | Отзыв/характеристика руководителя (форма) |

Компиляция: **XeLaTeX** (UTF-8, `fontspec`, шрифт Times New Roman из `corefonts`).
Сборка воспроизводится через Nix Flakes (`flake.nix`): `texliveSmall`, `texstudio`,
обёртка `compile.sh`, `FONTCONFIG_FILE` с корпоративными шрифтами.

**Главный артефакт — PDF отчёта, полностью соответствующий требованиям ГОСТ 7.32–2017.**

## 2. Источник требований — иерархия приоритетов

1. **Часть II настоящего файла** (§1–§27) — полный свод требований: параметры, образцы,
   правила нумерации, иллюстраций, таблиц, формул, ссылок, приложений, 20 типовых нарушений,
   вопросы для самоконтроля, соответствие макросам шаблона. **Перед любой правкой оформления —
   сверяться с ним.** Отдельного файла требований в репозитории нет — искать его не нужно.
2. `Оформление_ВКР_требования_стандарта_УрФУ_2022.pdf` (в корне, 92 с.) — первоисточник
   (ЭОР УрФУ, Плотникова И. Ю., Климова О. В., 2022). Ссылки вида «с. 40» в Части II — по
   печатной нумерации этого PDF. Если формулировка в Части II кажется неполной — читать PDF.
3. Шаблон `report/report.tex` — реализация требований; его преамбула задаёт поля, кегли,
   интервалы, нумерацию, подписи.

**Правило разрешения конфликтов:** требования → всегда в приоритете; если конкретная форма
кафедры (макет титульного листа, задания, отзыва) противоречит ЭОР, следовать форме
кафедры и **явно сообщать пользователю о расхождении**.

> ⚠️ PDF модель не читает напрямую (ошибка «does not support pdf input»). Текст извлекают
> так: `python3 -c "...pypdf..."` или `pdftotext` внутри `nix develop` (системный
> `pdftotext` в этом окружении сломан из-за glibc). Извлечение — по необходимости во
> временный каталог; текстовые дампы PDF в репозиторий не добавлять.

## 3. Сборка и проверка

```bash
# всё окружение (LaTeX + шрифты + compile.sh)
nix develop

# собрать все три документа (x2 прогона для ссылок и содержания)
compile.sh

# собрать только отчёт
compile.sh report/report

# вручную (из каталога документа, иначе артефакты уедут в корень; см. §3.1)
cd report && xelatex -interaction=nonstopmode -halt-on-error report.tex && xelatex report.tex
```

### 3.1. Куда попадают артефакты сборки (важно для проверок)

`compile.sh` перед запуском `xelatex` **переходит в каталог исходника** (`cd` + базовое имя
файла), поэтому `.aux`, `.log`, `.toc` и **PDF создаются рядом с `.tex`**, а в корне
репозитория после сборки оставаться артефактов **не должно**:

| Команда | Результат |
|---|---|
| `compile.sh report/report` | `report/report.pdf`, `report/report.log`, `report/report.aux`, `report/report.toc` |
| `compile.sh` (без аргументов) | то же для `assignment/`, `review/`, `report/` — каждый в свой каталог |
| `compile.sh report/report.tex` | эквивалентно `compile.sh report/report` (`.tex` нормализуется) |

Это же поведение совпадает с тем, как собирает TeXstudio, и делает относительные пути внутри
документа (`\includegraphics{fig/arch.pdf}`, `\input{...}`) **относительными каталога
документа** — см. §5.7.

Все артефакты (`*.aux`, `*.log`, `*.toc`, `*.pdf`) покрыты `.gitignore` без привязки к
каталогу, поэтому в коммит не попадают (проверено `git check-ignore` для вложенных путей).

Ручной запуск — **из каталога документа** (иначе артефакты уедут в текущий каталог):

```bash
cd report && xelatex -interaction=nonstopmode -halt-on-error report.tex && xelatex report.tex

# или из корня — с явным выходным каталогом
xelatex -output-directory=report -interaction=nonstopmode -halt-on-error report/report.tex
xelatex -output-directory=report report/report.tex
```

Проверки после сборки **обязательно** (пути — относительно корня репозитория; системные
`pdfinfo`/`pdftotext` вне `nix develop` **не работают** из-за несовместимости glibc):

```bash
grep -E '^! |LaTeX Error|Undefined control' report/report.log      # ошибки — их быть не должно
grep -n 'There were undefined references' report/report.log         # пусто = ссылки сошлись
grep -a "Output written" report/report.log                          # число страниц
pdfinfo report/report.pdf | grep Pages                              # альтернатива — в nix develop
ls *.aux *.log *.toc report.pdf 2>/dev/null                         # в корне быть не должно
```

Первый прогон `nix develop` может печатать `warning: Git tree ... is dirty` — это не ошибка.

`compile.sh` падает с **ненулевым exit-кодом** на первой же ошибке (`set -e` + `-halt-on-error`,
проверено на заведомо битом `.tex`), поэтому `compile.sh … && <проверки>` — надёжный страж;
полагаться только на текст лога не нужно.

## 4. Жёсткие правила оформления (краткий свод)

Полный текст — в Части II; здесь минимум, нарушение которого = правка отклоняется.

### 4.1. Параметры страницы и текста

| Параметр | Значение |
|---|---|
| Формат / сторона | A4, односторонняя печать |
| Поля | левое **30 мм**, правое **15 мм**, верхнее и нижнее **20 мм** |
| Абзацный отступ | **1,25 см** (= `\Абзац=35.4pt`) |
| Шрифт | **Times New Roman**, чёрный |
| Кегль | **14 пт** текст; **12 пт** таблицы, надписи и подрисуночные подписи |
| Интервал | **1,5** (= базовая высота строки 24,15 pt при 14 pt) |
| Переносы слов | **запрещены** (в преамбуле `\hyphenpenalty=10000` — не снимать!) |

### 4.2. Заголовки и нумерация

- Заголовки структурных элементов: **полужирные, ПРОПИСНЫЕ, по центру, без точки, без
  подчёркивания**, каждый элемент — **с новой страницы**.
- Разделы: `1 Наименование` (полужирный, с абзацного отступа, без точки в конце номера).
  Подразделы: `1.1 Наименование`. Пункты/подпункты (`1.1.1`) — только номер, без заголовка.
- Слово **«глава» не используется** (ГОСТ 7.32 не допускает).
- Точка после заголовка не ставится; несколько предложений в заголовке разделяются точкой;
  перенос слов в заголовках и в подписях рисунков/таблиц запрещён, в т. ч. на союзе/предлоге.
- Страницы: **арабские, внизу по центру, без точки, сквозные, включая приложения**.
  Титульный лист в нумерацию включается, но номер на нём **не печатается** (`\pagestyle{empty}`).
  Лист А3 считается за одну страницу.

### 4.3. Рисунок/таблица/формула/приложение — что обязательно

- Каждый рисунок и таблица **должны иметь ссылку в тексте до/рядом с собой**, слово пишется
  **полностью, без сокращения**: `рисунок 2`, `Таблица 3` (не «рис.», не «табл.», не
  «см. рисунок выше»). В середине предложения — строчными и согласованно по падежам
  (образец ЭОР: «в соответствии с рисунком 2»); с прописной — в нумерационном заголовке
  подписи: `Рисунок 1.2 – …`, `Таблица 1 – …`.
- Подпись рисунка: **под** рисунком, по центру, без точки: `Рисунок N – Наименование`;
  экспликация условных обозначений — перед подписью.
- Подпись таблицы: **над** таблицей, слева, без абзацного отступа: `Таблица N – Наименование`.
  Диагональные разделители в шапке запрещены; заголовки граф — по центру, боковика — по левому
  краю; перенос на другую страницу: `Продолжение таблицы N` + переносить и головку.
- **Раздел не может заканчиваться рисунком или таблицей** — после них обязателен вывод/анализ
  не менее одного абзаца.
- Формулы: отдельной строкой, посередине, ≥1 свободной строки выше/ниже, номер в круглых
  скобках справа `(1)`; экспликация со слова `где` **без двоеточия**, каждое значение — новой
  строкой, конец — точка с запятой; знаки подобия и функции (`max`, `lg`, `Re`) — прямым,
  латинские обозначения величин — курсивом.
- Приложения: с новой страницы, `ПРИЛОЖЕНИЕ А` / `(обязательное)` / заголовок ПРОПИСНЫМИ по
  центру без точки; буквы кириллицы **кроме Ё, З, Й, О, Ч, Ъ, Ы, Ь**; нумерация рисунков/таблиц/
  формул внутри приложения с буквой: `Рисунок А.1`, `Таблица А.1`, `(А.1)`; все приложения
  перечислены в содержании и на все даны ссылки в тексте.

### 4.4. Ссылки на источники

- Отсылки — **арабские цифры в квадратных скобках**: `[5]`, с конкретикой `[5, с. 20]`,
  диапазон `[2, с. 15–20]`, несколько `[1; 4, с. 30]`.
- Список источников — **в порядке появления ссылок в тексте** (не по алфавиту),
  нумерация `1.` с точкой, с абзацного отступа.
- Описание по ГОСТ Р 7.0.5: `Фамилия И. О. Заголовок : вид / авторы. — Город : Издательство,
  год. — N с.` (в ЭОР тире-разделители часто опущены — держать стиль, заданный в шаблоне:
  `Город: Изд-во, год. N с.`)

## 5. Шаблон `report/report.tex`: макросы и как их использовать

Преамбула шаблона — это «движок» оформления. **Её не править без крайней необходимости**:
все параметры §4 уже зашиты. Писать текст можно только макросами ниже.

### 5.1. Данные в преамбуле (редактировать при каждом заполнении)

```latex
\Исполнитель{...}   \Руководитель{...}   \Группа{...}   \Кафедра{...}   \Институт{...}
\Тема{...}          \Код{...}             \Специальность{...}  \Программа{...}
\Начало{...}        \Конец{...}           \Год{...}
```

Все подстановки идут из этих команд — **ФИО, группу, сроки, организацию выдумывать нельзя**,
при отсутствии данных запросить у пользователя. `\Кратко{ФИО}` даёт формат «Фамилия И. О.».

### 5.2. Структурные макросы

| Макрос | Результат |
|---|---|
| `\ОсновнаяЧасть` | включает нумерацию страниц, кегль 14/1,5, отступ, параметры формул — вызывается один раз после титульного листа |
| `\Элемент{Введение}` | структурный элемент: новая страница + ПРОПИСНЫЙ полужирный заголовок по центру + запись в содержание |
| `\Элемент*{…}` | то же, но **без** записи в содержание (звёздочка; используется внутри `\Содержание`) |
| `\Содержание` | готовый блок «СОДЕРЖАНИЕ» + автособираемое TOC — для оглавления использовать **только** его |
| `\Раздел{Название}` | `1 Название` (жирн., абз. отступ), в TOC; счётчик сквозной |
| `\Подраздел{Название}` | `1.1 Название`, в TOC |
| `\Пункт` | печатает `1.1.1 ` и ждёт текст; заголовка не имеет |
| `\Приложение{обязательное}{Название}` | `ПРИЛОЖЕНИЕ А` + `(обязательное)` + заголовок; сбрасывает счётчики рисунков/таблиц/формул и префиксует их буквой |

### 5.3. Текст и списки

```latex
Введённый в практику анализ показал три группы задач:
\begin{перечисление}
  \item первая группа,
  \item вторая группа,
  \item третья группа.
\end{перечисление}
```

- `\begin{перечисление}` (по умолчанию метка — тире `–`), варианты: `[буквы]` → `а) б) в)`,
  `[цифры]` → `1) 2) 3)`. Простые перечисления — через запятую, сложные — через точку с запятой.
- Тире в тексте: `\Тире{}` (это `–`); дефис `-` в перечислениях и подписях **запрещён**.
- Footnote (`\footnote{...}`) оформляется автоматически: 12 пт, с абзацного отступа.
- Пустые отступы строк: `\пусто[...]` — в основном тексте не нужен, интервалы заданы macro'ами.

### 5.4. Рисунки, таблицы, формулы

```latex
% Рисунок: [экспликация] {содержимое} {подпись + label}
\Рисунок[1 – вход; 2 – выход]{\includegraphics[width=0.7\linewidth]{risks.pdf}}%
{Архитектура системы анализа рисков\label{рис:arch}}
Схема показана на рисунке \ref{рис:arch}. После ссылки — вывод не менее одного абзаца.

% Таблица: окружение, подпись ставится автоматически над таблицей
\begin{таблица}{Сводка результатов\label{табл:res}}
  \begin{tabular}{|l|c|c|} \hline
    Заголовок графы & Заголовок графы & Заголовок графы \\ \hline
    Строка & 1 & 2 \\ \hline
  \end{tabular}
\end{таблица}
Результаты сведены в таблицу \ref{табл:res}. Здесь анализ результатов.
% при переносе на другую страницу: \ПродолжениеТаблицы

% Примечание к таблице/рисунку
\Примечание{данные получены на выборке из 12 источников.}

% Формула: standard equation + экспликация «где»
\begin{equation}
  S = v t,
\end{equation}
где $S$ \Тире{} путь, м; \\
\hspace*{\Абзац}$v$ \Тире{} скорость, м/с; \\
\hspace*{\Абзац}$t$ \Тире{} время, с.
```

### 5.5. Библиография

```latex
\begin{источники}
  \bibitem{gost} ГОСТ 7.32–2017. СИБИД. Отчёт о научно-исследовательской работе...
\end{источники}

Текст со ссылкой \cite{gost}.
```

Порядок `\bibitem` = порядок появления `\cite` в тексте (первым цитируемым — первый `\bibitem`).
Использовать `\bibliographystyle`/BibTeX **нельзя** — окружение `источники` заточено под ручную
нумерацию и формат ЭОР.

### 5.6. Чего нет в шаблоне и как добавлять

Элементы **РЕФЕРАТ**, **ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ**, **ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ** в
текущем `report.tex` отсутствуют. Если они нужны по форме кафедры — добавлять так:

```latex
\Элемент{Реферат}
Отчёт 42 с., 8 рис., 5 табл., 25 источн., 2 прил.   % итоговые числа — проставлять ВРУЧНУЮ после финальной сборки
Ключевые слова: практика, анализ рисков, ...
% 5–15 слов, им. падеж, в строку через запятые, без абз. отступа и без точки в конце.
% РЕГИСТР: по правилу ЭОР (с. 22) — прописными буквами, но образец ЭОР (с. 21) даёт строчные;
% в ЭОР противоречие — уточнить у кафедры/нормоконтролёра и держать единообразно.
...текст реферата ≤ 850 знаков...

\Элемент{Термины и определения}
В настоящей работе применяют следующие термины с соответствующими определениями \\
Термин – определение   % столбиком, без знаков препинания в конце
```

При добавлении не менять преамбулу — только использовать готовые `\Элемент` и текст.
(Проверить после добавления, что элемент попал в содержание: `\Элемент` сам вызывает
`\addcontentsline`.)

### 5.7. Файлы изображений

Изображения держать в `report/` (или `report/fig/`). **Пути в исходнике — относительные каталога
документа**, т. к. `compile.sh` собирает изнутри `report/` (§3.1): `\includegraphics{fig/arch.pdf}`,
а **не** `{report/fig/arch.pdf}`. XeLaTeX принимает PDF и PNG.

> ⚠️ **Внимание: `.gitignore` содержит `*.pdf` и `*.docx` без привязки к каталогу — паттерн
> действует на любой уровень вложенности.** Проверено: `git check-ignore -v report/fig/img.pdf`
> указывает на правило `*.pdf` из `.gitignore` (номер строки не фиксируем — файл правят,
> строки съезжают). Значит, PDF-иллюстрации в `report/fig/` **в git не попадут** и
> на другой машине отчёт не соберётся.
>
> Варианты (согласовать с пользователем):
> 1. конвертировать иллюстрации в PNG/JPG (`*.png`/`*.jpg` не игнорируются) — предпочтительно;
> 2. положить PDF в каталог, исключённый из игнора, и добавить в `.gitignore` строку вида
>    `!report/fig/*.pdf` (менять `.gitignore` только по явной просьбе);
> 3. `git add -f report/fig/img.pdf` — разовое принудительное добавление.
>
> После добавления иллюстрации **всегда проверять**: `git status --short report/` показывает
> файл, а не прячет его.

## 6. Порядок работы агента (workflow)

1. **Прочитать** Часть II (§23 «Типовые нарушения» Части II — как чек-лист) и текущий
   `report/report.tex`.
2. **Собрать факты** у пользователя / из `assignment/` и `review/`: тема, организация,
   сроки, задачи, что фактически делалось, результаты, приложения. **Не додумывать
   ФИО, даты, номера групп, названия организаций, технические результаты.**
3. **Заполнить преамбулу данных** (§5.1) и структуру: Введение → разделы → Заключение →
   источники → приложения.
4. **Писать по элементу за раз** (см. §7 «что писать»), после каждого рисунка/таблицы —
   абзац анализа.
5. **Собрать** (`compile.sh report/report`), проверить лог (§3).
6. **Прогнать чек-лист** (§8), показать пользователю diff и отчёт о расхождениях с формой
   кафедры.
7. **Коммит**: короткое повелительное наклонение, по-английски, как в истории git
   (`Fill in report introduction`, `Add risk analysis section`) — **не смешивать несколько
   документов в одном коммите**. Артефакты сборки не коммитить (см. `.gitignore`).

## 7. Содержание: что писать в каждом элементе

| Элемент | Требования (Часть II, §3–§12) |
|---|---|
| **Титульный лист** | форма кафедры; реквизиты: министерство, университет, институт/кафедра, вид и тип практики, тема, руководитель, исполнитель, группа, город и год. Не править макет без запроса |
| **Реферат** *(если нужен)* | ≤ 1 стр., оптимум **850 печатных знаков**; строка объёма `Отчёт N с., N рис., N табл., N источн., N прил.` (числа — вручную после финальной сборки); **5–15 ключевых слов** (именительный падеж, в строку, через запятые, без абзацного отступа и без точки в конце; регистр — см. §5.6, в ЭОР правило и образец расходятся); далее: объект, цель, методы, результаты и новизна, область применения, значимость |
| **Содержание** | автособираемое (`\Содержание`), включает введение, все разделы/подразделы/пункты с названиями, заключение, список источников, приложения с номерами страниц |
| **Введение** | актуальность, связь с другими работами, **объект** (на что направлен интерес) и **предмет** (угол зрения), **цель — одна**, **задачи** `1) ... 2) ...` = этапы движения к цели; для практики дополнительно: место, сроки, вид/тип практики, база |
| **Основная часть** | 2–3 раздела. (1) выбор направления: обзор, актуальность, методы; (2) процесс: что и как делалось — методы, инструменты, этапы; (3) результаты: оценка полноты решения задач, достоверность, сравнение с аналогами, отрицательные результаты. Для практики: описание организации-базы, постановка задачи, выполненные работы по этапам, полученные результаты |
| **Заключение** | краткие выводы по каждой задаче, оценка полноты решения, рекомендации по использованию результатов. **Без новых фактов и без ссылок на новую литературу** |
| **Список источников** | порядок появления ссылок; ГОСТ Р 7.0.5; электронные ресурсы — URL + `(дата обращения: дд.мм.гггг)` |
| **Приложения** | задание/дневник/программы/схемы/акты; статус обязательное/справочное; `ПРИЛОЖЕНИЕ А` и т. д. |

**Объём** (ориентир; для отчёта о практике конкретный задаёт кафедра): 30–60 стр. (бакалавр).

## 8. Definition of Done

Перед сдачей проверить:

- [ ] `compile.sh report/report` проходит дважды, в `report/report.log` нет `! `-ошибок,
      `undefined references` и `Label multiply defined`; **в корне репозитория артефактов нет**
      (`ls *.aux *.log *.toc report.pdf` пустой — см. §3.1).
- [ ] Поля/шрифт/кегли/интервал соответствуют §4.1 (не менялись в преамбуле).
- [ ] Заголовки: ПРОПИСНЫЕ, полужирные, без точки, каждый элемент с новой страницы.
- [ ] Нет слова «глава», нет «гл.»; нет `рис.`/`табл.` — в тексте только полное
      `рисунок N` / `таблица N` (со строчной и по падежам), в подписях — `Рисунок N – …`,
      `Таблица N – …`.
- [ ] На **каждый** рисунок, таблицу, формулу и приложение есть ссылка в тексте:
      `grep -o '\\label{[^}]*}' report/report.tex | sort` и сверить с `\ref{...}`;
      `grep -o '\\bibitem{[^}]*}'` сверить с `\cite{...}` — неиспользованных не остаётся.
- [ ] После каждого рисунка/таблицы есть абзац анализа; раздел не кончается иллюстрацией.
- [ ] В перечислениях — `\Тире{}`-тире/корректные метки, а не `-`.
- [ ] Формулы: номер справа в `( )`, экспликация `где` без двоеточия, каждая величина с новой
      строки, `;` в конце строк.
- [ ] Приложения: буквы без Ё, З, Й, О, Ч, Ъ, Ы, Ь; `(обязательное)`/`(справочное)`;
      нумерация внутри с буквой приложения.
- [ ] Отсылки `[N]` / `[N, с. M]`, список — по порядку появления.
- [ ] Реферат ≤ 1 стр. и 5–15 ключевых слов (если элемент используется).
- [ ] Объём в диапазоне (§7); не «надувать» его пустыми строками (`\пусто`) и переносами.
- [ ] Фактические данные (ФИО, сроки, организация) — подтверждены пользователем.
- [ ] Изменения закоммичены; артефакты сборки не попали в git.

## 9. Стиль текста

- Русский язык, научно-технический стиль, безличность или «мы/автор» последовательно.
- Термины — единообразно; при первом использовании латинский термин курсивом (in vivo и т. п.).
- Числы и единицы — по SI; обозначения величин курсивом, единицы прямым.
- Не использовать «watermark»-фразы, метафоры, разговорные обороты.
- Аббревиатуры: при первом упоминании расшифровка; более трёх обозначений →
  перечень сокращений (§5.6).

## 10. Ограничения агента

1. Не менять `flake.nix`, преамбулу «движка» (`wpar`, `wsz`, `geometry`...) и настройки
   шрифтов/полей — только если пользователь явно попросил.
   Исключение, сделанное по просьбе: `compile.sh` в `flake.nix` **намеренно** делает `cd` в
   каталог исходника, чтобы `.pdf`/`.aux`/`.log`/`.toc` лежали рядом с `.tex` (§3.1). Не
   «упрощать» это обратно к запуску из корня — иначе артефакты снова посылются в корень.
2. Не переписывать структуру `report/report.tex` на другой шаблон/класс (например,
   `reportsum`, `biblatex`, `\chapter` из other classes) — документ на `article` + свои макросы.
3. Не выдумывать содержание практики: нет данных — спрашивать.
4. Не «чинить» замечания нормоконтролёра молча: показывать diff, описывать, какое требование
   из какого раздела Части II закрыто.
5. При расхождении ЭОР и формы кафедры — решать в пользу формы кафедры и писать об этом.
6. Не трогать `*.docx` и исходные PDF в корне (это артефакты кафедры; в git игнорируются).

### 1. Общие требования к оформлению

#### 1.1. Сводка технических параметров (с. 14–16)

| Параметр | Требование |
|---|---|
| Носитель текста | одна сторона листа белой бумаги формата **А4** |
| Левое поле | **30 мм** |
| Правое поле | **15 мм** |
| Верхнее поле | **20 мм** |
| Нижнее поле | **20 мм** |
| Абзацный отступ | **1,25 см** (единый по всему тексту) |
| Гарнитура | **Times New Roman** |
| Цвет шрифта | **чёрный** |
| Кегль основного текста | **14 пт** |
| Кегль в таблицах, надписях на рисунках, подрисуночных подписях | **12 пт** |
| Междустрочный интервал | **1,5** |
| Заголовки 1-го и 2-го уровней | **полужирное начертание** |
| Заголовки 1-го уровня | **ПРОПИСНЫЕ** буквы |
| Заголовки 2-го и последующих уровней | **строчные** буквы |
| Выравнивание основного текста | по ширине, с абзацного отступа |

#### 1.2. Детализация требований

- **Поля.** Несимметричные размеры полей обусловлены необходимостью переплёта: готовая распечатанная работа обязательно переплетается (самостоятельно или в отделении оперативной полиграфии) (с. 14).
- **Последовательность настройки.** Автоматическую настройку полей необходимо провести **до начала оформления**: изменение размеров полей приводит к полной переверстке текста и рисунков (с. 14).
- **Настройка полей в MS Word:** главное меню → вкладка «Макет» («Разметка страницы») → кнопка «Поля» → выставить значения согласно таблице выше (с. 14, рис. 1 ЭОР).
- **Абзацный отступ.** Значение 1,25 см — стандартный отступ MS Word по умолчанию; проверить: вкладка «Абзац» (с. 15, рис. 2 ЭОР).
- **Начертания.** Для заголовков третьего и последующих уровней **может быть применена** гарнитура другого шрифта или курсивное начертание (с. 15–16).
- **Стили.** Автоматическое оформление стилей рекомендуется настроить до начала работы с текстом: чтобы не терять структурно-смысловую связь между частями работы и для настройки автособираемого содержания (с. 16, рис. 3 ЭОР; см. также с. 26).
- **Курсив** допускается для обозначения объектов (биология, геология, медицина, нанотехнологии, генная инженерия и др.) и написания терминов (например, *in vivo*, *in vitro*) и иных объектов и терминов латиницей (с. 16).
- **Акцентирование внимания.** Допускается выделение текста шрифтом иного начертания, чем у основного текста, но **того же кегля и гарнитуры**. Для написания определённых терминов, формул, теорем разрешается применять шрифты разной гарнитуры (с. 16).
- **Качество воспроизведения** (с. 39): независимо от способа написания работы качество напечатанного текста и оформления иллюстраций, таблиц, распечаток документов должно обеспечивать их чёткое воспроизведение; необходимо соблюдать равномерную плотность и чёткость изображения по всему отчёту; все линии, буквы, цифры и знаки должны иметь одинаковую контрастность по всему тексту.

### 2. Структура отчёта и рекомендуемый объём

#### 2.1. Основные структурные элементы (с. 12)

Перечисленные элементы являются **заголовками первого уровня** и оформляются как самостоятельные структурные единицы (каждый — с новой страницы, см. с. 40):

1. титульный лист;
2. реферат;
3. содержание;
4. термины и определения *(при наличии)*;
5. перечень сокращений и условных обозначений *(при наличии)*;
6. введение;
7. основная часть (текст отчёта / пояснительная записка);
8. заключение;
9. список использованных источников;
10. приложения *(при наличии)*.

- По сноске 4 (с. 12) для некоторых направлений обучения УрФУ в соответствии с приказом № 944/03 после титульного листа в состав элементов дополнительно включаются **задание на выполнение** (задание на проектирование), а при наличии — **перечень листов графических (демонстрационных) материалов**. Для отчёта о практике это задание на практику и отзыв/характеристика организации — сверяйтесь с формой, установленной кафедрой.

#### 2.2. Рекомендуемый объём (с. 10)

По приказу № 944/03:

| Квалификация | Объём |
|---|---|
| бакалавр | 30–60 страниц |
| специалист | 50–90 страниц |
| магистр | 50–120 страниц |

**Примечание.** ЭОР приводит объём для выпускных работ; для отчёта о преддипломной практике конкретный объём устанавливается программой практики и методическими указаниями кафедры. Ориентироваться следует на эти значения и на требования руководителя практики.

#### 2.3. С чего начинать (с. 12–13)

### 4. Реферат

#### 4.1. Назначение

Реферат — краткое изложение работы объёмом **не больше одной страницы текста**. Требование обусловлено производственной необходимостью: члены ГЭК/ГАК не всегда успевают прочитать работу полностью; сжатое изложение позволяет за несколько минут ознакомиться с сутью исследования, его объёмом, количеством переработанной литературы, общим количеством страниц (с. 22).

#### 4.2. Обязательные части (с. 22–23)

1. **Сведения об общем объёме** отчёта, количестве иллюстраций, таблиц, использованных источников, приложений — располагаются **с абзацного отступа, в строку, через запятые**:
   `Отчёт 65 с., 18 рис., 25 источн., 1 прил.`
2. **Перечень ключевых слов**: от **5 до 15** слов или словосочетаний из текста отчёта, максимально характеризующих содержание и обеспечивающих возможность информационного поиска. Приводятся **в именительном падеже**, печатаются **прописными буквами, в строку, через запятые**, **без абзацного отступа и переноса слов**, **без точки в конце перечня**:
   `Ключевые слова: учебник, верстка, макет, структурные особенности, визуально-полиграфические особенности`
3. **Текст реферата** — с абзацного отступа после ключевых слов; отражает сведения (в этой последовательности):
   - объект исследования;
   - цель работы;
   - методы или методология проведения работы;
   - результаты работы и их новизна;
   - область применения полученных результатов;
   - рекомендации по внедрению или итоги внедрения результатов;
   - оценка экономической эффективности или значимость работы;
   - прогнозные предположения о развитии объекта исследования.

#### 4.3. Дополнительные правила

- Если работа не содержит сведений по какой-либо из перечисленных структурных частей реферата, эта часть **опускается**, последовательность изложения сохраняется (с. 23).
- Оптимальный объём текста реферата — **850 печатных знаков с пробелами**, но не более одной страницы машинописного текста (с. 23).

**Примечание (адаптация).** Для отчёта о практике блоки 1–3 раскрываются как: описание организации-базы практики и постановки задачи; выполненные работы по этапам (с указанием методов, инструментов, программ, объёмов); результаты (разработанные модули, проведённые исследования, полученные данные) и их оценка.

### 12. Приложения

#### 12.1. Что включать (с. 36)

В приложения рекомендуется включать материалы, дополняющие текст работы, связанные с выполненной работой, если они **не могут быть включены в основную часть**:

- дополнительные материалы к отчёту;
- промежуточные доказательства и расчёты;
- таблицы вспомогательных цифровых данных;
- протоколы испытаний;
- заключение метрологической экспертизы;
- инструкции, методики, описания алгоритмов и программ, разработанных в процессе выполнения работы;
- иллюстрации вспомогательного характера;
- акты внедрения результатов исследования или их копии;
- копии документов (патент, авторские свидетельства).

Для отчёта о практике типичные приложения: задание на практику, календарный план/дневник, индивидуальное задание, примеры кода, распечатки результатов, схемы, акты внедрения.

#### 12.2. Правила оформления (с. 36–37)

- В тексте отчёта **на все приложения должны быть даны ссылки**; приложения располагают **в порядке ссылок** на них в тексте.
- В приложении указывается **статус**:
  - **обязательное** — если в нём отражены сведения, необходимые для понимания проведённого исследования;
  - **справочное** — если содержит промежуточные результаты исследования или примеры, возможные варианты решений.
- Каждое приложение размещают **с новой страницы** с указанием **в центре верхней части страницы** слова **ПРИЛОЖЕНИЕ**.
- Приложение должно иметь **заголовок**: прописные буквы, отдельная строка **по центру, без точки в конце**.
- Обозначения — **прописные буквы кириллического алфавита, начиная с А**, **за исключением Ё, З, Й, О, Ч, Ъ, Ы, Ь**; после слова ПРИЛОЖЕНИЕ следует буква, обозначающая последовательность. При полном использовании букв кириллического или латинского алфавита допускается обозначать приложения **арабскими цифрами**.
- Если приложение одно, оно обозначается **ПРИЛОЖЕНИЕ А**.
- Приложения выполняют на листах **А4**, допускается **А3**.
- Текст приложения при необходимости делят на разделы, подразделы, пункты, подпункты — они нумеруются **в пределах каждого приложения**, перед номером ставится обозначение приложения (например, 1.1 приложения А — А.1.1).
- Приложения имеют **общую со всей работой сквозную нумерацию страниц**.
- Все приложения перечисляются в **содержании** с указанием наименования и **статуса** (обязательное/справочное).

#### 12.3. Обозначение приложения (с. 37)

```
ПРИЛОЖЕНИЕ А
(обязательное)
РАСЧЁТ СЕБЕСТОИМОСТИ ИЗДАТЕЛЬСКОЙ ПРОДУКЦИИ
```

- Рисунки приложения: **Рисунок А.3**; таблицы: **Таблица А.1**; формулы: **(В.1)** (см. с. 49, 55, 61).

### 13. Заголовки структурных элементов

#### 13.1. Уровни заголовков (с. 40–41)

| Уровень | Пример из ЭОР | Начертание | Буквы | Расположение | Точка |
|---|---|---|---|---|---|
| 1-й (структурный элемент) | РЕФЕРАТ, СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ, СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ, ПРИЛОЖЕНИЕ | полужирное | ПРОПИСНЫЕ | по центру страницы, в середине строки | нет |
| 1-й (раздел основной части) | `РАЗДЕЛ 1 АНАЛИЗ ПУБЛИКАЦИЙ. ПОДГОТОВКА АВТОРСКОГО ОРИГИНАЛ-МАКЕТА…` | полужирное | ПРОПИСНЫЕ | с абзацного отступа, после порядкового номера | нет |
| 2-й (подраздел) | `1.1 Структурные особенности учебно-методических изданий` | полужирное | строчные (первая буква прописная) | с абзацного отступа, после номера | нет |
| 3-й и далее (пункт/подпункт) | `1.2.1` | может быть другой гарнитуры или курсив | строчные | с абзацного отступа | нет |

- Заголовки **первого уровня** оформляются полужирным начертанием прописными буквами, размещаются по центру страницы в середине строки, **без точки в конце, не подчёркивая**. **Каждый структурный элемент начинают с новой страницы** (с. 40).
- В перечне заголовков первого уровня ЭОР упоминается также **СПИСОК ИСПОЛНИТЕЛЕЙ** (характерен для отчётов о НИР; для отчёта о практике применяется, если предусмотрен формой) (с. 40).
- **Разделы и подразделы должны иметь заголовки**; **пункты и подпункты, как правило, заголовков не имеют** и являются заголовками последующего уровня, имеющими только порядковый номер (с. 40).
- Заголовки должны **чётко и кратко** отражать содержание разделов и подразделов (с. 41).
- Если заголовок включает несколько предложений, их разделяют **точками**; после заголовков **точка не ставится** (с. 40–41).
- **Переносы слов в заголовках не допускаются**; в заголовке нельзя переносить слова на союзе и предлоге (с. 40):

| НЕВЕРНО | ВЕРНО |
|---|---|
| Русское письмо на \| основе грамматики | Русское письмо \| на основе грамматики |
| Электродинамика и распростране- \| ние радиоволн | Электродинамика \| и распространение радиоволн |

### 14. Нумерация: страницы, разделы, перечисления

#### 14.1. Страницы (с. 42)

- Страницы нумеруются **арабскими цифрами**, сквозная нумерация **по всему тексту, включая приложения**.
- Номер страницы проставляется **в центре нижней части страницы без точки**.
- **Титульный лист включается в общую нумерацию, но номер на нём не проставляется.**
- Иллюстрации и таблицы, расположенные на отдельных листах, включают в общую нумерацию; иллюстрации и таблицы на листе **А3 учитываются как одна страница**.
- Настройка в MS Word: вкладка «Вставка» → «Номер страницы» (рис. 5, с. 42); чтобы убрать номер с титульного листа — двойной щелчок по нижнему колонтитулу и включение опции **«Особый колонтитул для первой страницы»** (рис. 6, с. 43).

#### 14.2. Разделы, подразделы, пункты, подпункты (с. 44)

- **Разделы:** порядковые номера в пределах всего отчёта, **арабскими цифрами без точки**, расположены **с абзацного отступа**.
- **Подразделы:** нумерация в пределах раздела; номер состоит из номера раздела и подраздела, разделённых **точкой**; **в конце номера подраздела точка не ставится**. Разделы, как и подразделы, могут состоять из одного или нескольких пунктов.
- **ГОСТ 7.32 не допускает** такого названия структурной части, как **«глава»**; в ряде кафедр есть традиция называть части «главами» — логично сохранить только нумерационные и тематические заголовки без слова «глава» или «раздел» (с. 44).
- Если раздел или подраздел состоит из **одного пункта**, пункт **не нумеруется и не отражается в содержании** (с. 44).
- Если текст подразделяется только на **пункты**, они нумеруются порядковыми номерами в пределах отчёта (с. 44).
- Пункты могут делиться на **подпункты** с порядковой нумерацией в пределах пункта: `4.2.1.1`, `4.2.1.2`, `4.2.1.3` (с. 44).

Пример построения (с. 43):

```
2 ВЕКТОРЫ ЭЛЕКТРОМАГНИТНОГО ПОЛЯ
2.1 Теория векторов
    Текст, текст…
2.1.1 Силовое воздействие на заряды
    Текст, текст…
2.1.2 Напряжённость электрического поля
    Текст, текст…
2.2 Уравнения электромагнитного поля
```

#### 14.3. Перечисления (с. 44–46)

- Приводятся **с абзацного отступа в столбик**.
- Перед каждым элементом следует ставить **тире (–)**, а **не дефис (-)** (с. 46).
- При необходимости **ссылки в тексте** на один из элементов перечисления вместо тире ставят **строчные буквы русского алфавита со скобкой**, начиная с буквы «а», **за исключением букв ё, з, й, о, ч, ъ, ы, ь** (с. 46).
- **Простые перечисления отделяются запятой, сложные — точкой с запятой** (с. 46).
- При наличии **конкретного числа** перечислений допускается перед каждым элементом ставить **арабские цифры, после которых — скобка**: `1) …, 2) …` (с. 45, 46).

Примеры из ЭОР:

```
Содержательная характеристика произведения имеет несколько аспектов:

Выпускная квалификационная работа должна обладать следующими
```

Многоуровневый список (с. 46):

### 15. Иллюстрации

#### 15.1. Общие правила (с. 48)

- К иллюстрациям относятся **чертежи, графики, схемы, компьютерные распечатки, диаграммы, фотоснимки**.
- Располагаются **непосредственно после текста**, где они упоминаются **впервые**, или **на следующей странице** (по возможности ближе к соответствующей части текста).
- **На все иллюстрации** в тексте приводятся ссылки; при ссылке слово **«рисунок» пишется полностью, без сокращения**, с указанием номера: «в соответствии с рисунком 2» (с. 48).
- Чертежи, графики, диаграммы, схемы должны соответствовать требованиям стандартов **ЕСКД** (Единой системы конструкторской документации) (с. 48).
- Количество иллюстраций должно быть **достаточным** для пояснения излагаемого текста (с. 48).

#### 15.2. Нумерация (с. 48–49)

- Все иллюстрации нумеруются **арабскими цифрами**; допускается **два типа нумерации**:

| Тип | Формула номера | Когда применять | Пример |
|---|---|---|---|
| **Сквозная** | порядковый номер по всей работе | по умолчанию | `Рисунок 1`, `Рисунок 2`, `Рисунок 3`; единственный рисунок обязательно обозначается «рисунок 1» |
| **Поглавная** | номер раздела + порядковый номер, через точку | когда рисунков много; облегчает проверку внутри раздела и исключает путаницу при добавлении рисунков | `Рисунок 2.1` |

- Иллюстрации **каждого приложения** обозначают отдельной нумерацией с добавлением перед цифрой обозначения приложения: `Рисунок А.3` (с. 49).
- Если в работе применена **поглавная** нумерация рисунков, **нумерация таблиц также должна быть поглавной**, и наоборот (см. с. 52).

#### 15.3. Подрисуночная подпись (с. 49–50)

- Кроме нумерационного заголовка, иллюстрация должна иметь **наименование** (тематический заголовок), раскрывающее содержание, и **пояснительные данные** (подрисуночный текст, **экспликацию**).
- **Экспликация** (сноска 6, с. 50): 1) составная часть подписи к иллюстрации, содержащая расшифровку условных обозначений деталей и частей изображения; 2) расшифровка буквенных обозначений величин, употребляемых в формуле.
- Слово **«Рисунок», его номер и через тире наименование** помещают **после пояснительных данных** и располагают **в центре под рисунком без точки в конце**.
- Если наименование рисунка состоит из нескольких строк, его записывают **через один межстрочный интервал**; приводят **с прописной буквы, без точки в конце**.
- **Перенос слов** в наименовании графического материала **не допускается**; запрещён перенос на союзах и предлогах (как в заголовках).

Образцы из ЭОР (с. 47, 50):

```
Рисунок 1.2 – Распределение упругих и электромагнитных волн по частоте

1 – верхний бьеф; 2 – плотина;
3 – гидропреобразователь; 4 – нижний бьеф
Рисунок 4.4 – Схема плотинного преобразования энергии реки
```

### 16. Таблицы

#### 16.1. Назначение и общие правила (с. 52)

- Для сопоставления данных цифровой материал оформляется в виде таблиц. **Таблица — особая форма передачи содержания**: организация слов и чисел в колонки (графы) и горизонтальные строки так, что каждый элемент одновременно является частью и строки, и колонки.
- Таблицы применяют **для наглядности и удобства сравнения показателей**.
- **Таблица не является рисунком** и призвана подтвердить научную мысль доказательной базой.
- Размер шрифта в таблице может быть таким же или **меньше на 1–2 пт** чем в основном тексте; при основном тексте 14 пт шрифт таблицы — **не менее 12 пт**, гарнитура — Times New Roman (с. 52).
- Таблица располагается **непосредственно после текста**, в котором упоминается **впервые**, или **на следующей странице**.
- **На все таблицы должны быть ссылки**; ссылка размещается в тексте **до** приведения таблицы; при ссылке полностью печатают слово **«Таблица»** с указанием её номера (нумерационный заголовок).

#### 16.2. Структура таблицы (с. 52–53)

Элементы таблицы по ЭОР:

- **нумерационный заголовок** (`Таблица 1`) и **тематический заголовок** (`– Характеристика стекла`) — над таблицей **слева, без абзацного отступа**, в формате:
  `Таблица Номер таблицы – Наименование таблицы`
- **головка** (заголовки граф), **боковик** (заголовки строк), **графы** (колонки), **строки**.

```
Таблица 1 – Характеристика стекла

Стекло        Удельный вес, H/м³   Предел прочности, Па
                                   при сжатии  при растяжении
Листовое      2,50                 99,0        6,7
Жаростойкое   2,53                 120,0       7,5
Кварцевое     3,23                 123,0       12,0
```

#### 16.3. Требования к заголовкам и оформлению (с. 53–55)

- Наименование таблицы должно отражать её содержание, быть **точным и кратким**; приводится **с прописной буквы, без точки в конце**.
- Если наименование занимает **две строки и более** — записывается **через один межстрочный интервал**.
- Заголовки граф и строк печатают **с прописной буквы**; подзаголовки граф — **со строчной**, если они составляют одно предложение с заголовком, или **с прописной**, если имеют самостоятельное значение. **В конце заголовков и подзаголовков точки не ставятся**. Названия заголовков и подзаголовков указывают **в единственном числе**.
- Таблицу **слева, справа, сверху и снизу ограничивают линиями**. **Разделять заголовки и подзаголовки боковика и граф диагональными линиями не допускается**.
- **Заголовки граф выравнивают по центру**, заголовки строк — **по левому краю**.
- Горизонтальные и вертикальные линии, разграничивающие строки, **допускается не проводить**, если их отсутствие не затрудняет пользование таблицей.
- При **делении таблицы на части** допускается её головку или боковик заменять соответственно номерами граф и (или) строк; при этом нумеруют арабскими цифрами графы и (или) строки первой части таблицы.

#### 16.4. Нумерация таблиц (с. 55)

- Таблицы (кроме таблиц приложений) нумеруются **арабскими цифрами сквозной нумерацией**.
- Таблицы каждого приложения — отдельная нумерация с добавлением обозначения приложения: `Таблица А.1`.
- **Если в работе одна таблица**, она обозначается `Таблица 1` (в приложении А — `Таблица А.1`).
- При большом объёме допускается нумеровать таблицы **в пределах раздела**: номер = номер раздела + порядковый номер, через точку (например, во 2-м разделе третья таблица — `Таблица 2.3`).
- Тип нумерации таблиц **должен совпадать** с типом нумерации рисунков (сквозная ↔ сквозная, поглавная ↔ поглавная).

#### 16.5. Перенос таблицы на другую страницу (с. 54–55)

- Таблицу с большим количеством строк **допускается переносить**.
- Над **первой** частью таблицы один раз слева указывают слово **«Таблица»**, её номер и наименование; над **другими частями** также слева пишут **«Продолжение таблицы»** и указывают номер:

```
Продолжение таблицы 6

Занятия                                   Муж   Жен
Ходить на вечеринки или устраивать их      16    19
Смотреть телевизор                          9    15
```

- Для удобства чтения при переносе следует перенести **помимо боковика и граф также головку таблицы**.
- Важно, чтобы **в конце предыдущей или в начале следующей страницы не оставалась одна строка тела таблицы**; в этом случае таблицу лучше целиком перенести на следующую страницу.

#### 16.6. Повторяющийся текст в таблице (с. 56)

- Текст, повторяющийся в строках одной и той же графы и состоящий из **одиночных слов**, заменяют **кавычками**.
- Ставить кавычки **вместо повторяющихся цифр, буквенно-цифровых обозначений, знаков и символов не допускается**.
- Если текст повторяется, то **при первом повторении** его заменяют словами **«то же»**, далее — кавычками:

```
Таблица 1 – Виды полиграфической продукции

Вид продукции          Продукция      Сезонная    Цена, руб.
учебник для школьников печатная       да          600
художественная лит-ра  то же           нет         854
подарочная книга       – ʺ –          да          1380
```

#### 16.7. Обязательный вывод (с. 56)

> Текст раздела или какой-то структурной единицы работы **не должен оканчиваться таблицей или рисунком**: и таблицы, и рисунки приводятся как вспомогательный материал или доказательная база. После таблицы или рисунка следует дописать **вывод или анализ представленных данных — не менее одного абзаца**.

### 17. Примечания и сноски

#### 17.1. Примечания (с. 57)

- Примечания приводят, если необходимы пояснения или справочные данные к содержанию текста, таблиц или графического материала.
- Слово **«Примечание»** печатают **с прописной буквы с абзацного отступа, не подчёркивая**.
- Помещают **непосредственно после** текстового, графического материала или таблицы, к которым относятся примечания.
- Если примечание **одно**: после слова «Примечание» ставится **тире**, текст печатается **с прописной буквы**, **не нумеруется**.
- **Несколько примечаний** нумеруют по порядку **арабскими цифрами без точки**.

Образец из ЭОР (с. 57):

```
Таблица 8 – Семейное положение респондентов, % от числа ответивших*

Варианты ответа                                       2012  2016  2020
Холост (не замужем)                                     87    87    85
Женат (замужем), состою в незарегистрированном браке     4     3     4
Разведён(а)                                             2     1    0,3

* Примечание – Начиная с 2003 года в перечень вариантов ответов о семейном
положении был включён ещё один параметр «гражданский (незарегистрированный)
брак».
```

#### 17.2. Сноски (с. 58–59)

- При необходимости дополнительного пояснения допускается использовать примечание, оформленное **в виде сноски**.
- **Знак сноски** ставят **без пробела** непосредственно после того слова, числа, символа, предложения, к которому даётся пояснение.
- Знак сноски указывается **надстрочно арабскими цифрами**; допускается вместо цифр использовать знак **звёздочки (\*)**.
- Сноску располагают **с абзацного отступа в конце страницы**, на которой приведено поясняемое слово (словосочетание или данные).
- Сноску **отделяют от текста короткой сплошной тонкой горизонтальной линией с левой стороны страницы**.
- В MS Word: «Ссылки» → «Вставить сноску» (рис. 7, с. 58–59).

### 18. Формулы и уравнения

#### 18.1. Размещение и перенос (с. 61)

- Формулы и уравнения приводят в тексте **отдельной строкой**; **выше и ниже** каждой формулы оставляют **не менее одной свободной строки**.
- Если уравнение не умещается в одну строку, его переносят **после знака равенства (=)**, после знаков плюс (+), минус (–), умножения (×), деления (:) или других математических знаков; **на новой строке знак повторяется**.
- При переносе формулы на знаке операции умножения применяют **только знак «×»**.
- Формулы располагают **посередине строки**.
- **В конце формулы**, как правило, должен стоять знак препинания **в контексте того предложения**, в которое входит формула.

#### 18.2. Нумерация формул (с. 61)

| Случай | Формат | Пример |
|---|---|---|
| сквозная | арабские цифры **в круглых скобках в крайнем правом положении на строке** | `(1.2)`, одиночная формула — `(1)` |
| в пределах раздела | номер раздела и порядковый номер через точку | `(3.1)` |
| в приложениях | обозначение приложения + порядковый номер | `(В.1)` |
| ссылки в тексте | в скобках | «в формуле (1)», «в формуле (2.1)», «в формулах (3)–(5)» |

#### 18.3. Экспликация (пояснение значений символов) (с. 61)

- Пояснение значений символов и числовых коэффициентов приводится **непосредственно под формулой** **в той же последовательности**, в которой они представлены в формуле.
- **Значение каждого символа и числового коэффициента — с новой строки**.
- **Первую строку пояснения начинают со слова «где» без двоеточия, с абзацного отступа**; за ним — буквенное обозначение первой величины, **тире** и расшифровка, **завершаемая точкой с запятой**; далее — остальные величины.

Образец из ЭОР (с. 60):

```
Vтетр = (Vп · d) / Ст ,                                        (1.2)

где Vтетр – объём книжного издания в тетрадях;
    Vп – объём издания в печатных листах;
    d – доля бумажного листа;
    Ст – число страниц в тетради.
```

### 19. Шрифтовое оформление обозначений

Требования разделов «Шрифтовое оформление обозначений», «Шрифтовое оформление индексов», «Символы элементов в названиях химических соединений» (с. 62–66):

#### 19.1. Общие правила

- В одном и том же тексте **не следует применять одни и те же буквы** для обозначения разных величин или **разные буквы** для обозначения одной и той же величины.
- **Буквы латинского алфавита**, обозначающие физические величины, набирают **курсивом**; **цифры** при этом — **прямым**.
- Буквы **греческого, немецкого готического, русского** алфавитов (главным образом в экономической литературе) набирают **шрифтом прямого начертания**.

#### 19.2. Обозначения, набираемые латиницей в прямом начертании

| Группа | Примеры |
|---|---|
| Числа подобия | Ar (Архимеда), Bi (Био), Bo (Больцмана), Bu (Бугера), Eu (Эйлера), Fo (Фурье), Fr (Фруда), Ga (Галилея), Gr (Грасгофа), Ki (Кирпичева), M (Маха), Nu (Нуссельта), Pe (Пекле), Pr (Прандтля), Re (Рейнольдса), St (Стантона), Zh (Жуковского) и др. |
| Тригонометрические, гиперболические, обратные круговые, обратные гиперболические функции | sin, cos, tg, ctg, sh, ch, arc tg и т. п. |
| Температурные шкалы | K (Кельвин), °C (Цельсий), °R (Ренкин), °F (Фаренгейт) |
| Условные математические сокращения | max, min, opt, const, idem, lim, Lim, lg, ln, log, det, exp и др. |
| Химические элементы и соединения | Cl, Fe, C₂, H₆ |

#### 19.3. Векторные величины

- Обозначаются буквами латинского и греческого алфавитов **курсивным полужирным** начертанием.
- Допускается применение **прямого полужирного** начертания, а также обозначение буквами латинского алфавита в **светлом прямом начертании со стрелкой наверху**.

#### 19.4. Индексы

- В индексах **буквы латинского алфавита набираются курсивом**, за исключением случаев, когда в качестве индекса используются математические обозначения, которые принято набирать прямым (цифровые обозначения, буквы русского алфавита). Примеры: `Cp` — теплоёмкость при постоянном давлении p; `σx, y` — где x, y — составляющие тензора напряжения σ; `an` — коэффициент с n = 1, 2, 3…; **но**: `1min`, `а1`, `d2`.
- **Сложные индексы** сочетанием простых:
  - два-три сокращённых **русских** слова — отделяют друг от друга **точками**, после последнего сокращения точку **не ставят** (пример ЭОР: `νгр.` — частота граничная верхняя);
  - **цифры, буквы латинского или греческого алфавита** и сокращённые русские слова знаками препинания **не отделяют** (пример: `Iизгg`);
  - **несколько чисел** в цифровой форме отделяют одно от другого **запятой** (пример: `i1, 2, 3`);
  - **десятичную дробь** или сокращённое слово/букву — дробь отделяют от сокращённого слова или буквы **точкой с запятой** (пример: `σ0,2; пл`).

#### 19.5. Химические названия

- **Символы элементов** в названиях химических соединений (C, O, N, S, Si, P, As, Sb и др.) набирают **прямыми прописными буквами латинского алфавита светлого начертания** и присоединяют к другим частям названия **дефисами**; знаки вращения плоскости поляризации **(+) и (–)** заключают **в скобки** и соединяют с другими частями названия **дефисами**. Пример: `L-(+)-глицериновый альдегид`.
- **Обозначения конфигурации L, D, R, S** набирают **прописными курсивными** буквами латинского алфавита светлого начертания. Пример: `пента-О-фцетил-α-D-глюкоза`, `D-глюкоза`, `L-глюкоза`.
- **Обозначения особенностей строения** (орто-, мета-, пара-, о-, м-, п-, н-, втор-, трет-, цис-, транс-, син-, анти-, трео-, эритро- и т. д.) набирают **строчными курсивными** буквами и **отделяют дефисом**. Пример: `ди-трет-бутиловый эфир`, `о-фенилендиамин`, `цис-дихлорэтен`.

### 20. Библиографические ссылки

#### 20.1. Общие правила (с. 68–69)

- Соблюдение авторского права: **на все использованные в тексте заимствованные документы необходимо оформить ссылку**; ссылка оформляется на список использованных источников в конце отчёта.
- При нумерации ссылок приводится **сплошная нумерация для всего текста отчёта в целом**.
- **Порядковый номер ссылки (отсылки)** приводят арабскими цифрами **в квадратных скобках в конце текста ссылки**; порядковый номер библиографического описания источника в списке **соответствует номеру ссылки**.
- Ссылаться можно на документ **в целом**, на его **разделы и приложения**, на **конкретную страницу**.
- **Список источников формируется в порядке упоминания документа по тексту (не по алфавиту)** (с. 68).
- Затекстовая библиографическая ссылка содержит (с. 69): заголовок; основное заглавие документа; общее обозначение материала; сведения, относящиеся к заглавию; сведения об ответственности; сведения об издании; выходные данные; физическую характеристику документа; сведения о местоположении объекта ссылки в документе (если ссылка на часть документа); сведения о серии; обозначение и порядковый номер тома или выпуска (для многочастных/сериальных документов); сведения о документе, в котором опубликован объект ссылки; примечания; международный стандартный номер.
- **В библиографическом описании пробел перед двоеточием ставится обязательно** — для разделения зон заглавия и вида издания (с. 69).

#### 20.2. Примеры отсылок в тексте (с. 68)

```
«… Данное явление упоминается А. Резером в его книге [1, с. 20], а также
подробно рассмотрено уральскими исследователями [2, с. 35; 4, с. 154–162].
… собрали статистические данные и проанализировали их [1, с. 254–272; 3–5]».

«Качество продукции регламентируется ГОСТ Р 7.0.99 [25], который с 2021 года
устанавливает новые требования к предоставлению услуг».

«Более подробно об этом явлении рассказывается в работе М. А. Мишина
в разделе 7.4 [36, с. 456]».
```

Пример соответствия текста и списка (с. 70):

```
В тексте: «В своей книге О. В. Климова и Е. А. Березовская разделяют несколько
            техник редакторского чтения [21, с. 58–60]».
В списке: 21. Климова О. В., Березовская Е. А. Редактирование: общий курс :
          учебно-методическое пособие. Екатеринбург: Изд-во Урал. ун-та, 2014. 120 с.
```

### 22. Пошаговый алгоритм оформления

1. **До набора текста** (с. 13–16):
   - создать файл; выставить поля 30 / 15 / 20 / 20 мм (Макет → Поля);
   - задать шрифт Times New Roman: 14 пт, чёрный, интервал 1,5; для подписей и таблиц — 12 пт;
   - установить абзацный отступ 1,25 см (Абзац → Отступ первой строки: 1,25 см);
   - настроить стили для заголовков 1-го, 2-го и последующих уровней (полужирный; 1-й уровень — ПРОПИСНЫЕ по центру; 2-й — строчные с прописной буквы с абзацного отступа);
   - включить нумерацию страниц внизу по центру и «Особый колонтитул для первой страницы».
2. **Титульный лист** — по форме кафедры (см. раздел 3).
3. **Реферат** (≤ 1 стр., 850 знаков, 5–15 ключевых слов) — см. раздел 4.
4. **Содержание** — автособираемое оглавление по стилям (раздел 5).
5. **Термины и определения**, **перечень сокращений** — при наличии >3 обозначений (разделы 6–7).
6. **Введение**: актуальность, объект, предмет, цель (одна), задачи (нумерация `1) …`), база и сроки практики (раздел 8).
7. **Основная часть**: разделы/подразделы с нумерационными и тематическими заголовками; текст, иллюстрации, таблицы, формулы — по правилам разделов 13–19; обязательные ссылки на каждый рисунок, таблицу и приложение; вывод после каждого рисунка/таблицы.
8. **Заключение**: выводы по задачам, результаты, рекомендации (раздел 10).
9. **Список использованных источников**: в порядке появления ссылок, `[N]` / `[N, с. M]` (разделы 11, 20–21).
10. **Приложения**: каждое с новой страницы, `ПРИЛОЖЕНИЕ Б`, статус, заголовок прописными без точки, своя нумерация рисунков/таблиц/форму (`Б.2`, `Таблица Б.1`, `(Б.1)`) (раздел 12).
11. **Проверка**: прогнать чек-лист раздела 23 и вопросы раздела 24.

### 26. Соответствие требованиям в LaTeX-шаблоне репозитория

Шаблон `report/report.tex` уже реализует требования ЭОР. Соответствия:

| Требование ЭОР | Реализация в `report/report.tex` |
|---|---|
| Поля 30 / 15 / 20 / 20 мм | `\usepackage[a4paper,left=30mm,right=15mm,top=20mm,bottom=20mm]{geometry}` (с. 14) |
| Гарнитура Times New Roman | `\setmainfont{Times New Roman}` (с. 15) |
| 14 пт основной текст, 12 пт подписи/таблицы | `\newcommand{\wтекст}{\wsz{14}{24.15}}`, `\newcommand{\wподпись}{\wsz{12}{13.8}}` (с. 15) |
| Интервал 1,5 для 14 пт | базовая высота строки `24,15 pt` = 16,1 pt × 1,5 (одинарный интервал для 14 пт — 16,1 pt) |
| Абзацный отступ 1,25 см | `\newdimen\Абзац \Абзац=35.4pt` (1,25 см = 35,4 pt) (с. 15) |
| Нумерация страниц — внизу по центру, без точки; титульный лист без номера | `\ps@гост` (номер в центре нижнего колонтитула), `\pagestyle{empty}` для титульной страницы, включение нумерации с `\ОсновнаяЧасть` (с. 42–43) |
| Заголовки 1-го уровня: полужирные, ПРОПИСНЫЕ, по центру, без точки, с новой страницы; структурный элемент — с новой страницы | `\Элемент{…}`: `\clearpage`, `\textbf{\MakeUppercase{…}}`, выравнивание по центру; добавление в содержание |
| Заголовки разделов/подразделов 1, 1.1 — полужирные, с абзацного отступа | `\Раздел{…}` (`\arabic{wsec}\ #1`, `\parindent=\Абзац`), `\Подраздел{…}` (`1.1`) (с. 40–41) |
| Пункты и подпункты — только порядковый номер | `\Пункт` выводит `1.1.1` без заголовка (с. 40, 44) |
| «Глава» не используется | команды `\Раздел`/`\Подраздел` формируют нумерацию без слова «глава» (с. 44) |
| Перечисления: тире, с абзацного отступа в столбик; варианты `а)`, `1)` | окружение `перечисление` с меткой `\Тире` (–) и опциями `буквы` / `цифры` (с. 44–46) |
| Иллюстрации: подпись «Рисунок N – Наименование» в центре под рисунком, без точки; экспликация перед подписью; нумерация в приложении `А.1` | `\Рисунок[экспликация]{…}{Наименование\label…}`, `\thewfig` переопределяется на `\thewapp.\arabic{wfig}` внутри `\Приложение` (с. 47–50) |
| Таблицы: «Таблица N – Наименование» слева над таблицей, 12 пт; «Продолжение таблицы N» | окружение `таблица`, `\Таблица`, `\ПродолжениеТаблицы`; `\wподпись` = 12 pt (с. 51–55) |

| Примечания: «Примечание – …» с абзацного отступа, без точки-номера у единственного | `\Примечание{…}` (с. 57) |
| Сноски: надстрочный знак, в конце страницы с абзацного отступа, 12 пт | `\footnote` + переопределение `\@makefntext` (кегль 12 pt, абзацный отступ) (с. 58) |
| Формулы: отдельной строкой, номер `(1)` / `(В.1)` справа, отступы не менее строки; экспликация со слова «где» | `equation` + `\abovedisplayskip/\belowdisplayskip=24.15pt`; в основном тексте нумерация сквозная `\arabic{equation}`, внутри `\Приложение` `\theequation` переопределяется на `\thewapp.\arabic{equation}` (с. 60–61). Поглавная нумерация `(3.1)` не настроена — при необходимости добавьте `\renewcommand{\theequation}{\arabic{wsec}.\arabic{equation}}` |
| Список источников: `[N]` в тексте, нумерация арабскими с точкой, порядок появления | окружение `источники`, `\@biblabel{#1.}`, `\cite` | 
| Приложения: `ПРИЛОЖЕНИЕ А`, статус в скобках, заголовок ПРОПИСНЫМИ по центру без точки, нумерация без Ё, З, Й, О, Ч, Ъ, Ы, Ь | `\Приложение{обязательное}{Наименование}`, `\w@letter` (с. 36–37) |
| Содержание, Введение, Заключение, Список источников как отдельные элементы, каждый с новой страницы | `\Содержание`, `\Элемент{Введение}`, `\Элемент{Заключение}`, окружение `источники` (внутри вызов `\Элемент{Список использованных источников}`) |

**Замечания по шаблону** (что стоит проверить при оформлении):

- Текст раздела **не должен заканчиваться** рисунком или таблицей — после них нужен вывод не менее одного абзаца (в шаблонах это проиллюстрировано строками «Вывод по рисунку», «Вывод по таблице»).
- Структурные элементы **РЕФЕРАТ, ТЕРМИНЫ И ОПРЕДЕЛЕНИЯ, ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ** в текущем шаблоне `report.tex` отсутствуют — при необходимости добавьте их вызовами `\Элемент{Реферат}` и т. п. и заполните по разделам 4, 6, 7 настоящих требований.
- Если выбираете **поглавную** нумерацию рисунков (`Рисунок 1.2`), переводите на поглавную и нумерацию таблиц, и наоборот (с. 52). В текущем `report.tex` используется сквозная.

Файлы `assignment/assignment.tex` (задание) и `review/review.tex` (отзыв руководителя) — формы кафедры; их параметры листа и шрифтов задаются шаблонами форм (см. `geometry` в этих файлах) и не подчиняются требованиям к основному тексту отчёта.
